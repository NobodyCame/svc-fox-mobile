The optional Legacy engine calls into an installed `simple-voice-call` mod when available. Fox Mobile does not bundle that mod's classes; the Simple Voice Call mod ID and Java package appear only as runtime compatibility targets. The bundled JLayer decoder has its own LGPL-2.1 notice in `src/main/resources/META-INF/licenses/`.
