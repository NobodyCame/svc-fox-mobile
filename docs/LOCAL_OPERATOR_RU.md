# Локальный оператор Fox Mobile для Minecraft 26.3

У клиента с Fox Mobile 1.3.24 оператор выбирается при подключении. Если игровой сервер объявляет канал Fox Mobile, клиент использует локального оператора. На сервере без канала используется HTTPS-адрес из настроек клиента. При сбое уже выбранного локального оператора клиент показывает ошибку и не отправляет тот же звонок или голосовое на другой сервер.

## Установка

- Purpur: положить `fox-mobile-operator-mc26.3-purpur-1.3.24.jar` в `plugins`.
- Fabric: положить `svc-fox-mobile-mc26.3-fabric-1.3.24.jar` в `mods` на сервере и у игроков. Для одиночного мира и LAN организатору достаточно установить клиентский Fabric JAR, он запустит оператор в самом мире. Остальным игрокам нужен тот же клиент.
- Для передачи звука используется Simple Voice Chat. На выделенном сервере Fabric и у клиентов установите совместимые сборки SVC для Fabric, на Purpur — серверный плагин SVC.

На Windows x64 и Linux x64/ARM64 (glibc 2.28+) готовые JAR распаковывают и запускают собственную среду CPython. Устанавливать Python на этих системах не нужно. На другой платформе можно указать путь к своему Python с зависимостями из `backend/requirements.txt`: параметр `python` в конфиге плагина или JVM-аргумент `-Dfoxmobile.python=/path/to/python` для Fabric. Сведения об ошибках запуска есть в серверном журнале и файле `operator-errors.log`.

## База и администрирование

Плагин хранит данные в `plugins/FoxMobileOperator/`. Fabric использует `fox-mobile-operator/` внутри каждого мира. Резервируйте папку после остановки игрового сервера. В ней находятся SQLite и ключи для идентификации оператора и шифрования записей. Права на каталог должны быть ограничены учётной записью сервера. Оператор получает UUID и имя из игровой сессии. На серверах с прокси подлинность аккаунтов зависит от настройки прокси и сервера.

Для администрирования остановите сервер и запускайте `runtime/operator_stdio.py --admin <действие>` из папки базы через встроенный интерпретатор (путь зависит от ОС) или совместимый Python. Команды чтения — `players`, `short-list` и `org-list`. Команды `assign-number`, `link-number`, `short-number` и `org-configure` получают JSON через stdin. Поля совпадают с существующей админкой, внутренняя область организаций называется `local`.

Безопасное подключение не требует открывать ещё один порт. Локальная база независима от внешнего HTTPS-сервиса. Старые персональные номера, очереди и голосовые не копируются из внешней БД автоматически.

## Перенос контактов

На целевом сервере откройте **Контакты → Перенос**, выберите сохранённый сервер или профиль из резервной копии и нажмите «Скопировать в текущий профиль». Копируются номера, подписи, избранное и настройки рингтонов. Контакты с совпадающим номером в целевом профиле сохраняются. Если на новом сервере человек сменил номер или UUID, проверьте его контакт перед звонком. Мелодии из локальных файлов нужно перенести отдельно при смене компьютера.

## Сборка

```powershell
python tools/package_operator_runtime.py
.\gradlew.bat :jar :purpur-operator:jar
```

В автономных артефактах есть серверные Python-модули. Опубликованный JAR позволяет извлечь эти модули.
Сборка из публичных исходников без серверных модулей и команда `gradlew :jar -PfoxClientOnly` дают обычный Fabric-клиент, который умеет подключаться к локальному оператору на сервере.
